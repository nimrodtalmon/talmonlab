Contribution Graph

Contributions (models, theorems, datasets, experiments, …) are the nodes. Arcs say how one contribution builds on another: an experiment validates a model, a theorem is about a model.

Contribute: add a contribution and what it builds on, or add an arc between existing contributions.

Curate: create a curator and accept contributions and arcs. Accepting something also accepts what it builds on (an assumption can be accepted alone); un-accepting removes what is built on it.

Front: the accepted contributions that nothing accepted builds on yet. Export it as JSON.
